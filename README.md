# HayHome — SolidJS

Аренда и продажа жилья в Армении. Ключевая идея продукта: **объявление живёт, пока владелец подтверждает, что жильё свободно** (SMS-код раз в 72 часа), жалоба «уже сдана» мгновенно убирает объявление из выдачи. Публикация бесплатна: честное поведение (подтверждения вовремя, отсутствие жалоб) приносит токены, а 100 токенов дают VIP-продвижение на 7 дней.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # предпросмотр сборки
```

Ноль внешних UI-библиотек: SolidJS + Vite, карта — Yandex Maps JS API 3.0.

## Yandex Maps

Единственный источник ключа — переменная окружения `VITE_YANDEX_MAPS_API_KEY` (см. `.env.example`), в коде ключ не хардкодится. Без ключа, при ошибке SDK/Referer, таймауте или ошибке инициализации карта показывает честное состояние: сообщение о временной недоступности, безопасную ссылку на точку в Yandex Maps и кнопку «Повторить», которая перезапускает загрузку без перезагрузки страницы. В dev-режиме под сообщением дополнительно показывается техническая причина (нет ключа / ошибка SDK или Referer / таймаут / ошибка инициализации); в проде — только общий текст, без деталей и без ключа.

Интерфейс поддерживает RU/EN/ՀՅ, но карта Yandex всегда грузится с локалью `ru_RU` — единственной стабильной локалью SDK v3 на момент внедрения. Смена языка интерфейса не перезагружает уже загруженную карту (переключение языка не меняет локаль загрузчика). Адреса в интерфейсе остаются локализованными независимо от локали карты.

Домен и тариф ключа настраиваются только в консоли Yandex (console.yandex.ru), не в коде. Один ключ обслуживает все языки интерфейса — заводить отдельный аккаунт или ключ под каждый язык не нужно, локаль карты не зависит от страны аккаунта. Перед релизом в allowlist HTTP Referer ключа должны быть указаны:

```
http://localhost:5173/*
http://127.0.0.1:5177/*
https://<production-domain>/*
```

Первые два — адреса локальной разработки (Vite dev-сервер и alt-хост); третий — шаблон, замените `<production-domain>` на реальный домен продакшена перед выпуском.

```
src/
  index.jsx            точка входа
  App.jsx              каркас: шапка, роутинг экранов, модалки, тосты

  data.js              справочники: города, районы, продавцы, 24 объявления
  i18n.js              словарь ՀՅ / RU / EN + tr() и dict()
  theme.js             цвета и переиспользуемые стили
  components/

    BottomNav.jsx      нижняя навигация (мобильная)

    ListingCard.jsx    карточка объявления
    PhotoSlot.jsx      плейсхолдер фото: drag-and-drop или выбор файла

    modals/            Filters, Report, How, Sms, Gallery
  screens/
    Search.jsx         поиск, фильтры, сортировка, скелетоны, пустое состояние
    Listing.jsx        карточка объекта, история подтверждений, продавец
    MapScreen.jsx      карта Еревана (Yandex Maps), «искать в этой области»
    Favs.jsx           избранное со статусами
    Chat.jsx           переписки с автоответами владельцев
```

## Как устроено состояние

`src/store.js` — один `createStore`. Состояние сохраняется в `localStorage` (ключ `hayhome.state.v2`, старый `bnak.state.v2` мигрируется автоматически) через `createEffect`: язык, избранное, аккаунт, свои объявления, подтверждения, переписки.

Селекторы (`visible()`, `statusOf()`, `cardOf()`, `myItems()`) — обычные функции, читающие стор, поэтому они реактивны внутри JSX без дополнительных подписок.

## Демо-данные

24 объявления по пяти типам сделок (аренда, посуточно, продажа, новостройки, коммерческая) в шести городах. Адреса (город, район, улица) хранятся тройкой `[հայերեն, русский, English]` и полностью переключаются вместе с интерфейсом. SMS-код в демо — любой из 4 цифр.
